# FactoryXChange 2.0 — Service Map

An interactive map of the FactoryXChange 2.0 service marketplace: 17 consortium partners and
their 73 live services, arranged so a user can move from a client need to a specific partner
service. It supports FXC collaboration and the work of Digital Strategists.

Live map: https://earlyprototype.github.io/fxc-service-map/

Built with the knowledge-graph-kit: https://github.com/earlyprototype/knowledge-graph-kit

## Structure

- **6 category hubs:** Technology, AI, Data, Business, Skills, Ecosystem.
- **73 service nodes**, each coloured by one of the 5 EDIH pillars — Test Before Invest,
  Skills & Training, Support to Find Investment, Partnerships & Networking, Data & AI Value Chain.
- **17 partner nodes.** 14 deliver bookable services; 3 (ICHEC, Monaru, Piquant) hold consortium
  roles, with ICHEC co-delivering one service.
- **Edges:** solid = a service's primary category; dashed = a secondary category; light = the
  delivering partner.

## Using it

| Action | Result |
|---|---|
| Click a category | Its services, Creative Spark listed first |
| Click a service | Card with pillar, categories, delivering partner and contact, and a link to the FXC page |
| Click a partner | Remit, "route a client here when…", website, and full service list |
| Search | Matches service names, descriptions, and partner routing text |
| Pillar checkboxes | Show or hide each pillar's services |
| Secondary categories toggle | Show or hide the dashed second-category edges |
| Copy Pathway Info | Copies the services currently in view to the clipboard as text |
| Ask AI | Chat that matches a plain-language need to services |
| Drag a node | Physics runs while dragging and settles when idle |

## Copy Pathway Info

Copies the services currently in view — after any pillar filtering, category/partner focus, or
search — to the clipboard as a plain-text list (service, partner, category, pillar, description,
FXC link). Narrow the view first, then copy that subset to paste into an email, a document, or an
LLM. With no filter or focus applied, it copies all 73.

## AI Service Finder

An optional chat that matches a plain-language client need to services. It is supplied the full
catalogue and returns matching services by name, each with the delivering partner and the FXC
page link, drawing only on the supplied catalogue.

To enable: copy `chat_config.template.json` to `chat_config.json` (gitignored), add an API key
(Gemini or Anthropic), and run `chat_server.py`. The key is used server-side only and is not sent
to the browser.

## How it's built

- **Static site:** `index.html` + `_data/entities.json` + the vis-network library.
- **Data:** generated by `build_fxc_map.py` from its curated service tables and
  `rich_descriptions.json`. Re-running it updates both the map and the index.
- **Service index:** `FXC_Service_Index.md` — the 73 services grouped by partner with FXC links.
- **Chat backend:** `chat_server.py` serves the map and, when configured, the AI chat.

## Running it

```
python chat_server.py
# open http://localhost:8020/index.html
```

The map, search, and Copy Pathway Info run without a key. The AI chat requires a configured key.

## Data source

Partner and service data was compiled from live marketplace product pages and the FXC store
sitemap. Category, secondary category, and pillar for each service are assigned in
`build_fxc_map.py`.

## Limitations

- Category, secondary-category, and pillar assignments are defined in the build script.
- The interface targets desktop and is not yet adapted for mobile.
- The AI chat requires an API key and the `chat_server.py` backend running; the rest of the map
  is static.
